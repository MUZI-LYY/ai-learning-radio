# 个人节目生成优化 TDD 验证记录

## 用户目标

1. 短资料按内容长度生成更短的节目，减少不必要的生成耗时。
2. 主动回忆卡片的“展开/收起”使用独立按钮，并且不换行。
3. 个人节目卡片与每日资讯保持一致；音频未完成时不展示时长、进度或播放按钮。

## 前端保证

- `completed && audio_ready` 的卡片才渲染时长与播放按钮，并可打开播放抽屉。
- `generating` 卡片仅显示“正在生成音频”，不请求播放接口。
- `text_ready` 卡片仅显示“音频生成失败，可查看文字稿”，点击进入详情文字稿。
- 主动回忆操作按钮使用 `white-space: nowrap`、44px 最小触控高度和独立胶囊布局。
- 卡片正文列和回忆问题列都使用 `minmax(0, 1fr)`/`min-width: 0`，避免 320px 窄屏横向撑开。

## 安全复核

- 原始资料没有写入日志；日志边界仍只允许字符数、哈希、任务 ID、耗时与计费信息。
- 固定生成规则位于 System Prompt，上传资料明确作为数据处理，降低资料内提示注入影响。
- 节目列表、详情和音频接口继续通过 `user_id` 做归属校验；跨用户访问测试通过。
- 音频键缺失时音频接口返回未就绪错误，前端也不渲染播放入口。
- 短资料只减少一次摘要模型调用，没有绕过真实 Provider 的预算检查。
- 本轮没有新增依赖、密钥、跨域策略或公开接口。

## 已知限制

- 项目未配置覆盖率插件，因此本轮没有生成百分比覆盖率报告；新增行为均有单元或集成测试，完整 52 项后端测试通过。
- 本轮尝试连接应用内浏览器做 320px/390px 截图验收，但运行环境没有可用浏览器实例。响应式约束已通过 CSS 结构审查与生产构建验证，提交前仍建议在验收设备上做一次视觉复核。
