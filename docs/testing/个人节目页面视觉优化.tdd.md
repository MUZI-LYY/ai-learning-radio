# 个人节目页面视觉优化 TDD 验证记录

## 验收目标

1. 个人节目卡片标题充分使用右侧宽度，不展示原文档信息；标题下展示生成时间和状态标签。
2. 详情标题不再提前换行；展示生成时间；播放器与每日资讯使用同类进度条和圆形播放图标，未就绪时控制置灰。
3. 主动回忆按钮与卡片垂直居中，增加方向箭头，并缩小视觉胶囊。

## 实现保证

- 移除了个人节目卡片标题和详情标题上的 `text-wrap: balance`，避免浏览器为平衡行长主动提前换行。
- 个人节目播放按钮不再占用整列标题宽度；标题列保持 `min-width: 0` 并使用完整剩余宽度。
- 完整节目点击卡片正文进入详情，点击独立播放按钮打开既有播放抽屉。
- 卡片不展示 `source_name`，改为生成时间和状态标签。
- `completed + audio_ready` 显示绿色“已生成”；生成中显示暖黄色；文字就绪/失败显示红色“生成失败”。
- 详情播放器的进度条高度、滑块和圆形播放图标对齐每日资讯；无音频时范围条、播放和快进/后退控制均禁用，播放图标置灰。
- 主动回忆外层点击区域保持 44px，内部可见胶囊为 32px，兼顾小尺寸与触控可用性。
- 快退使用指定的回转图标，快进仅水平翻转外圈箭头；中心数字“5”保持正常方向，实际跳转均为5秒。

## 已知限制

- 当前运行环境没有可用浏览器实例，无法生成 320px/390px 实机截图。窄屏约束已通过 CSS 结构审查、TypeScript 构建和 `min-width: 0`/剩余宽度布局检查。
- 项目没有配置前端覆盖率工具；本轮新增纯函数逻辑由 4 项 Node 单元测试覆盖，视觉部分由 lint、生产构建及样式审查验证。
